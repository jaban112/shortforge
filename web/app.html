이 파일 하나로 GitHub repo 생성 → 코드 푸시 → YouTube/Instagram 연결 → 무인 가동. 터미널 없음. 키는 네 브라우저와 네 GitHub secrets에만 간다 — 이 페이지는 서버가 없다.

1. GitHub 미연결

토큰: github.com/settings/tokens/new (classic, scopes repo + workflow) → Generate → 붙여넣기.

2. YouTube 미연결

Google Cloud에서 OAuth 클라이언트(데스크톱 앱) 하나만 만들면 된다. 아래 순서대로, 5분.

클릭 순서 펼치기
  1. 새 프로젝트 만들기 (이름 아무거나)
  2. YouTube Data API v3 → 사용 설정
  3. OAuth 동의 화면 → 외부 → 앱 이름·이메일 → 저장 → "앱 게시(프로덕션)" 버튼 누르기 ← 안 누르면 토큰이 7일마다 죽음
  4. 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 데스크톱 앱 → 클라이언트 ID / 보안 비밀번호 복사
대기

3. Instagram 선택

공개 URL 호스팅 필요 없음(resumable upload). 계정을 프로페셔널로 바꾸고 Meta 앱에서 토큰 버튼 한 번.

클릭 순서 펼치기
  1. 인스타 앱 → 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 → 크리에이터
  2. Meta 앱 만들기 → 사용 사례 "Instagram" (없으면 Other → Business)
  3. 앱 대시보드 → Instagram → API setup with Instagram login → Generate access tokens → Add account → 로그인·허용 → Generate token → 복사
